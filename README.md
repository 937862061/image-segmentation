# 图片框选裁剪工具

一个基于HTML5 Canvas的图片裁剪工具，支持多选择框、自由调整和批量导出功能。

## 功能特性

- ✅ **图片上传**: 支持JPG、PNG、GIF、BMP、WebP格式
- ✅ **多选择框**: 可创建多个选择框进行批量裁剪
- ✅ **紧凑选区列表**: 裁剪缩略图、编号和尺寸一目了然，仅当前选区展开编辑
- ✅ **精确裁剪**: 输入原图坐标和宽高，锁定比例，方向键微调
- ✅ **撤销重做**: 保留当前图片最近50步选区操作，删除后可直接撤销
- ✅ **自由调整**: 支持拖拽移动和8个方向的大小调整
- ✅ **快捷键缩放**: Ctrl+/- 进行图片缩放，滚轮缩放
- ✅ **批量导出**: 一键导出所有选择框内容
- ✅ **专业工作台**: 浅色紧凑顶栏承载上传、导出和缩放，左侧管理选区，右侧保留大画布
- ✅ **响应式界面**: 桌面与平板保持左右布局，760px及以下采用上下布局
- ✅ **键盘操作**: 明确的焦点提示、原生导出弹窗和快捷键指南

## 使用方法

### 基本操作

1. **打开图片**:
   - 点击顶部"打开图片"或画布中的"选择一张图片"按钮选择文件
   - 或直接拖拽图片文件到操作区域
2. **创建选择框**: 在图片上按住鼠标左键拖拽创建选择框；点击左栏"新建选区"后，可在已有框内部创建重叠选区
3. **选中选择框**: 点击选择框或左侧条目激活，当前选区展开X、Y、宽度和高度输入；眼睛按钮可临时隐藏全部选区查看原图
4. **调整选择框**: 
   - 拖拽选择框内部可移动位置
   - 拖拽边缘和角落的手柄可调整大小
   - 在左栏输入精确尺寸，勾选"锁定比例"后输入与拖拽均保持比例；方向键移动1像素，Shift+方向键移动10像素
5. **删除选择框**: 右键点击选择框选择删除，或按Delete键
6. **导出图片**: 点击"导出选区"按钮，选择格式、前缀与保存方式；任意数量的选区均可选择ZIP下载，文件名示例实时更新，左栏底部保留导出结果

### 快捷键

- `Ctrl + +`: 放大图片
- `Ctrl + -`: 缩小图片  
- `Ctrl + 0`: 重置视图
- `Ctrl + 1`: 设置为100%缩放
- `Tab`: 画布获得焦点且有活动选区时切换选择框；按`Esc`取消选中后，可用`Tab`离开画布
- `Shift + Tab`: 反向切换选择框
- `Delete/Backspace`: 删除当前选择框
- `Esc`: 取消当前操作
- `按住空格`: 临时拖动画布，松开恢复原模式
- `方向键`: 移动当前选区1像素；配合`Shift`移动10像素
- `Ctrl + Z`: 撤销选区操作
- `Ctrl + Shift + Z` / `Ctrl + Y`: 重做选区操作（macOS可使用Command）

### 鼠标操作

- **左键拖拽**: 创建新选择框（选择模式）或拖动图片（拖动模式）
- **左键点击**: 选中选择框
- **右键点击**: 显示删除菜单
- **滚轮**: 缩放图片（需在图片区域内）
- **拖拽文件**: 直接拖拽图片文件到操作区域上传

## 技术特性

- 纯前端实现，无需服务器

- 支持高分辨率图片处理
- 响应式设计，适配不同屏幕尺寸

### 核心类说明

- `ImageCropApp`: 主应用类，负责整体协调
- `ImageManager`: 图片管理，处理加载、显示和缩放
- `SelectionManager`: 选择框管理，处理创建、编辑和删除
- `CanvasRenderer`: Canvas渲染器，负责绘制图片和选择框
- `EventHandler`: 事件处理器，处理鼠标和键盘事件
- `ExportManager`: 导出管理器，处理图片裁剪和下载

## 使用限制

- 图片文件大小限制: 10MB
- 图片尺寸校验目前未启用，超大图仍可能占用较多内存
- 选择框最小尺寸: 10×10像素
- 缩放范围: 10%-500%
